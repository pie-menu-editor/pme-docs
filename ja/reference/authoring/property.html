Property¶

Property(メニューの種類 PROPERTY)は、ユーザープロパティを 1 つ定義します。 定義には型、引数、Enum 項目、コールバック、保存先、Property ID が含まれます。 定義は項目名で読み取り、変更します。 Property Stack は Property Stack で説明します。

関数

用途

read_pm()

定義を property に入れて返します。

update_property()

定義、保存先、Property ID を変更します。

関連項目: 設定を Property のスイッチにする。

Property を読み取る¶

read_pm(pm_uid)["property"] は、update_property() が受け付ける項目名で表した定義に、 registered_property_id、digest、diagnostics を加えたものです。 Property の型と保存先に該当する項目だけが入ります。Property の定義 を参照してください。 値はエディターに表示される値です。読み取りでは Getter を評価しません。

>>> pme.editing.read_pm(pm_uid)["property"]
{'type': 'BOOL', 'size': 1, 'default': False, 'expand': True,
 'horizontal': True, 'restore_default': False, 'get': None, 'set': None,
 'update': None, 'init': None, 'storage': None, 'property_id': 'my_toggle',
 'property_id_locked': False, 'registered_property_id': 'my_toggle',
 'digest': '42aaaef6...', 'diagnostics': []}

新しい Property は、コールバックを持たず、値を保存する Boolean です。

diagnostics には、保存されている定義の問題が入ります。

code

原因と追加のキー

callback_compile_error

保存されたコールバックに構文エラーがあります。field がそのコールバックを示し、 severity は "warning" です。

argument_unreadable

保存された引数が Python のリテラルではありません。field が引数を示し、 text に保存されたテキストが入ります。項目にはエディターの既定値が表示されます。

値の置き場所¶

storage が値の所有者を決めます。registered_property_id は Property が登録された名前です。

storage

値の所有者

読み方

None

Addon Preferences。PME が値を 1 つ持ちます。

pme.props(registered_property_id)。

"Object" などの ID 型名

その型の各データブロックが、registered_property_id という名前の属性として自分の値を持ちます。

getattr(data_block, registered_property_id)。pme.props() はこの値を持ちません。pme.props(registered_property_id) は None を返すか、 Addon Preferences で同じ ID を使う別の Property の値を返します。

 
prop = pme.editing.read_pm(property_uid)["property"]
name = prop["registered_property_id"]
if prop["storage"] is None:  # Addon Preferences: one value
    value = pme.props(name)
    widget = f"L.prop(props(), {name!r})"
else:  # "Object": a value on each object
    value = getattr(bpy.context.object, name)
    widget = f"L.prop(C.object, {name!r})"

Property が無効の間、registered_property_id は空です。 Property ID の規則は Property ID と移行 にあります。

Property の定義¶

read_pm()["property"] の項目です。最後の 3 つ以外は update_property() が受け付けます。 既定値 は、一度も設定されていない項目にエディターが表示する値です。 引数 default、min、max、step、precision、subtype、unit は、 同じ名前で Blender の bpy.props の関数に渡されます。 update_property() で None を渡すと、その引数は既定値に戻ります。

初期化の規則¶

エディター自身の規則が、この順に適用されます。 同じ呼び出しで渡した値は、これらの初期化のあとに適用されます。

関数¶

pme.editing.update_property(pm_uid, changes, *, expected_digest=None, dry_run=False)¶

Property の定義、保存先、Property ID を、エディターと同じ処理で変更します。

すべての変更を、最初の書き込みの前に検査します。1 つでも拒否されれば、何も書き込みません。 そのあと、変更を 3 つのグループに分け、決まった順序で保存します。

パラメータ:

  • pm_uid (str) -- Property の UID。

  • changes (dict) -- 項目名と新しい値の対応。項目名は Property の定義 の項目のうち、読み取り専用のもの以外です。 部分指定です。指定しない項目は、初期化の規則 による変化を除き、 値を保持します。None は引数をエディター既定値に戻し、コールバックを削除します。

  • expected_digest (str or None) -- read_pm()["property"]["digest"]。保存されている Property が変わっている場合、更新は stale_property で拒否されます。

  • dry_run (bool) -- 変更を検査し、書き込まずに返ります。

戻り値:

下で説明する結果。

戻り値の型:

dict

例外:

  • TypeError -- changes がマッピングではない。multiselect、 expand、horizontal、restore_default、 property_id_locked が bool ではない。コールバックが文字列でも None でもない。property_id が文字列ではない。storage が None でも空でない文字列でもない。items がマッピングのシーケンスではない、項目の identifier が文字列ではない、または uid、name、icon が文字列でも None でもない。expected_digest が文字列でも None でもない。dry_run が bool ではない。

  • ValueError -- 項目名が不明。type が 5 つの型のいずれでもない。 size が 1〜32 の整数ではない。項目に uid、identifier、name、icon 以外のキーがある。UID がない、不正、または曖昧。メニューが Property ではない。

  • RuntimeError -- Blender のメインスレッド以外から呼ばれた、PME の読み込みが完了していない、または PME の Preferences を利用できない。

グループ

group

実行される条件

保存処理

storage

エディターの保存先の設定。移動先の保存先に合わせて、新しい Property ID を選ぶことがあります。

property_id

保存されている Property ID または Lock が、要求されたものと異なる。 保存先グループが選んだ ID も含みます。

エディターの Edit Property ID。

definition

その他の項目が保存値と異なる。

エディターの各項目のあと、Blender への 1 回の登録。

各グループの終了時点で、Property は完成した形です。 groups は実行したグループ、pending は実行しなかったグループを示します。

ステータス

共通の語彙は ステータスの値 にあります。

意味

definition_registration_failed

グループ

Blender が保存した定義の登録を拒否しました。registration に詳細が入ります。

例

新しい Property を、長さの単位を持つ 0〜1 の Float にします。

created = pme.create_pm(pme.PmCreationSpec("PROPERTY", name="Bevel Width"))
before = pme.editing.read_pm(created.pm_uid)["property"]
result = pme.editing.update_property(
    created.pm_uid,
    {"type": "FLOAT", "default": 0.1, "min": 0.0, "max": 1.0, "unit": "LENGTH"},
    expected_digest=before["digest"],
)
assert result["status"] == "committed", result["diagnostics"]

補足

  • storage が変わるとき、要求された、または保持される Property ID を、 移動先の保存先で検査します。

  • 検証、保存、読み取りのいずれもコールバックを実行しません。On Init も実行されません。

  • 保存値は通常の登録の規則に従います。エディターと同じく、type や size を変えると保存値は破棄されます。失敗後に保存値は復元されません。

  • 確定したグループ、または unknown で終わったグループは、 read_pm()["version"] を 1 増やします。

  • 選択中のメニューと、編集中の下書きは変わりません。

  • 定義グループの保存中に発生した例外は、保存した定義を復元したあとで再送出されます。 その注記に、復元を確認できたかどうかが記されます。再試行の前に read_pm() を呼んでください。

  • この呼び出しは、Preferences のディスクへの保存、Undo ステップの追加、 Property の表示を行いません。
