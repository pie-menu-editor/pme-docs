オーサリング API¶

オーサリング API は、pme パッケージとその pme.editing モジュールを通じて、 Python から PME のメニューを作成・読み取り・編集・書き出しします。 Python Console、Text Editor、ほかのアドオン、Blender を操作する AI エージェントから呼び出します。 スロットの中(Command、Custom、Poll)に書くコードは別の話題で、スクリプティング で説明します。

ページ一覧¶

各ページは単独で読めます。基本事項 と 結果とガード は、 すべての編集関数が従う規則を定めます。API 全体が Experimental です。

実行中の API を読み込む¶

例では import pme を使います。これは 起動オプション で設定する任意の短縮エイリアスです。 エイリアスが無効な場合は、有効化済みアドオンのパッケージを名前で読み込みます。 起動設定の変更も Blender の再読み込みも不要です。

import bpy
import importlib

packages = [
    addon.module for addon in bpy.context.preferences.addons
    if addon.module.rsplit(".", 1)[-1].replace("-", "_") == "pie_menu_editor"
]
if len(packages) != 1:
    raise RuntimeError(f"Select the enabled PME package: {packages}")
pme = importlib.import_module(packages[0] + ".api")
print(pme.ADDON_ID)

  • このコードは、bl_ext.<repository>.pie_menu_editor としてインストールした Blender Extension と、 Extension ID にハイフンを使うもの(bl_ext.<repository>.pie-menu-editor)も見つけます。 モジュール名はリポジトリの ID に従うため、比較ではハイフンとアンダースコアの違いを無視します。

  • 複数のパッケージが該当する場合は、編集の前に目的のインストール先を特定します。 このコードは、その一覧を付けて RuntimeError を送出します。

  • 明示的な読み込みで得た pme 変数は、エイリアスと同じ API です。 この変数を使うコードでは import pme を省きます。

クイックスタート¶

import pme

# Runtime package identity (Legacy add-on or Blender Extension)
addon_id = pme.ADDON_ID

# Find a menu
pm = pme.find_pm("My Pie Menu")
pm = pme.find_pm(uid="pm_7f3c2k3h")

# Invoke a menu
pme.invoke_pm("My Pie Menu")
pme.invoke_pm(uid="pm_7f3c2k3h")

# List menus
all_menus = pme.list_pms()
pie_menus = pme.list_pms(mode="PMENU", enabled_only=True)
tags = pme.list_tags()

# Execute code
result = pme.execute("bpy.ops.mesh.primitive_cube_add()")
print(result.success, result.error_message)

# Evaluate an expression
value = pme.evaluate("len(C.selected_objects)")

# Validate JSON
result = pme.validate_json(json_string)
for err in result.errors:
    print(err.code, err.message)

後方互換¶

PME1 の pme.context と、Command のグローバル props() は引き続き利用できます。 PME の Command スロット内にある既存の props() スクリプトは、そのまま動作します。

# These still work in PME2
pme.context.open_menu("My Menu")
pme.context.event.mouse_x
pme.context.add_global("my_var", value)
props("MyCounter", 10)

新しいコードでは pme.execute() と pme.invoke_pm() を使います。
