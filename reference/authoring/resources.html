Resources¶

pme.resources reads the registered resource folders and icon folders, the script and icon files in them, and the resolution of a script reference. It reads the resource configuration PME currently uses and changes nothing. From an external script, pme is the short alias or the explicit package import.

Added in version 2.2.0: Read-only queries for registered folders, script and icon files, and script reference resolution. The API is Experimental.

Function

Purpose

list_folders()

Returns the registered resource folders with their current status.

list_icon_folders()

Returns the registered icon folders with their current status.

list_files()

Lists the script and icon files in those folders.

resolve_script()

Resolves a script reference as script execution does.

Results are immutable dataclasses. dataclasses.asdict() converts one to a dictionary, including the nested folder.

Folders¶

pme.resources.list_folders()¶

Return the registered resource folders in their saved order, with their current status.

Returns:

One entry per registered folder. Missing locations are included.

Return type:

tuple[ResourceFolderInfo, …]

Raises:

RuntimeError – The resource settings could not be read and no previous valid configuration is available. The message is "Resource settings are unavailable".

Notes

  • When no resource folder is registered, the result is empty. No default folder is created.

pme.resources.list_icon_folders()¶

Return the registered icon folders in their saved order, with their current status.

Icon folders are registered separately from resource folders.

Returns:

One entry per registered icon folder. name is "".

Return type:

tuple[ResourceFolderInfo, …]

Raises:

RuntimeError – The resource settings could not be read and no previous valid configuration is available. The message is "Resource settings are unavailable".

Notes

  • An empty result means that only the bundled icons are used. No default folder is created.

Files¶

pme.resources.list_files(kind=None)¶

List the existing script and icon files in the registered folders, including files that no slot uses.

Each call reads the active resource configuration and the file system again.

Parameters:

kind (str or None) – None for both kinds, "script" or "icon".

Returns:

The files found and the locations that could not be read.

Return type:

ResourceFileListing

Raises:

  • ValueError – kind is another value. The message is "kind must be None, 'script', or 'icon'".

  • RuntimeError – The resource settings could not be read and no previous valid configuration is available. The message is "Resource settings are unavailable".

Scan scope

Kind

Files listed

Scripts

Files ending in lowercase .py anywhere in each resource folder, also outside scripts/, because relative script references are resolved from the folder itself. Folders whose name starts with . and __pycache__ are skipped. Directory symbolic links are followed; each real directory is visited once per registered folder.

Icons

Files ending in lowercase .png directly in each icon folder, except names with the reserved _intr_ prefix. Files with conflicting names and names starting with _ (hidden in the Custom picker) are included. This is not a list of icons confirmed to be selectable or drawable.

Example

Collect the registered folders and files as JSON for another tool:

from dataclasses import asdict
import json
import pme

folders = pme.resources.list_folders()
listing = pme.resources.list_files()

payload = {
    "folders": [asdict(folder) for folder in folders],
    "files": [asdict(item) for item in listing.files],
    "issues": [asdict(issue) for issue in listing.issues],
}
print(json.dumps(payload, ensure_ascii=False, indent=2))

Notes

  • files is a complete inventory only when issues is empty. A folder that is not available contributes an issue and no files. A path that fails during the scan contributes an issue; the rest of its folder is still listed.

  • A registered resource folder or icon folder that is missing is an issue.

  • With kind=None, scripts come first, then icons. Folders follow registration order; names are sorted within each directory.

  • Files with the same name in different folders are separate entries.

  • Contents are not executed or decoded.

  • Changes that an external editor makes to the resource settings file are loaded on the next startup or when the add-on is enabled again.

Script references¶

pme.resources.resolve_script(reference)¶

Resolve a script reference with the resolver that script execution uses, without running the script.

A slot stores the path of a file inside a registered folder relative to that folder, such as scripts/modeling/align.py. The resolved absolute path identifies the file found now.

Parameters:

reference (str) – An absolute path or a relative reference.

Returns:

The resolution status and the matching files.

Return type:

ScriptResolution

Search order

reference

Locations checked

Absolute path

That path only.

assets/examples/scripts/...

The bundled examples in the add-on package only.

Any other relative reference

Every registered resource folder, with \ read as /. The add-on package is checked only when no registered folder has a candidate and every registered location could be inspected. In the package, a scripts/... reference also finds the bundled examples at their earlier locations.

Status

status

Meaning

resolved

One file was found. Read permission and Python syntax are not checked.

missing

No matching file was found.

ambiguous

Two or more distinct files match.

unavailable

A location could not be resolved or inspected, so resolution could not be completed.

Example

Build a command string for a slot. This neither runs the script nor edits a slot:

import pme

reference = "scripts/modeling/align.py"
result = pme.resources.resolve_script(reference)

if result.status == "resolved":
    command = f"execute_script({reference!r})"
    print(command)  # execute_script('scripts/modeling/align.py')
else:
    print(result.status, result.candidates)

Notes

  • Distinct files are separate candidates even when their contents are the same. Paths that lead to the same real file count as one candidate.

  • ambiguous takes precedence over unavailable.

  • Files can change after the call. Script execution resolves the reference again.

class pme.resources.ScriptResolution¶

Result of resolve_script().

Attribute

Type

Value

reference

str

The reference argument.

status

str

resolved, missing, ambiguous or unavailable.

resolved_path

str or None

Absolute path of the file when status is resolved; None otherwise.

candidates

tuple[str, …]

Paths of the matching files found: one for resolved, two or more for ambiguous, none for missing, those that could be inspected for unavailable.

Scope¶

  • The functions do not execute scripts, decode images, create directories or migrate settings.

  • Which slots use a file is not reported. Slot references are not updated when a file is moved or renamed.
