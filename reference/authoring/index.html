Authoring API¶

The Authoring API creates, reads, edits and exports PME menus from Python through the pme package and its pme.editing module. It is called from the Python Console, the Text Editor, another add-on, or an AI agent driving Blender. Code written inside a slot (Command, Custom, Poll) is a different subject, described in Scripting.

Pages¶

Every page can be read on its own. Concepts and Results and guards define the rules that every editing function follows. The whole API is Experimental.

Importing¶

The examples use import pme, the optional short alias configured in Boot Options. When the alias is disabled, the enabled add-on’s package is imported by name. This needs no change to the startup configuration and no reload of Blender:

import bpy
import importlib

packages = [
    addon.module for addon in bpy.context.preferences.addons
    if addon.module.rsplit(".", 1)[-1].replace("-", "_") == "pie_menu_editor"
]
if len(packages) != 1:
    raise RuntimeError(f"Select the enabled PME package: {packages}")
pme = importlib.import_module(packages[0] + ".api")
print(pme.ADDON_ID)

  • The snippet also finds a Blender Extension installed as bl_ext.<repository>.pie_menu_editor, and one whose extension ID uses hyphens (bl_ext.<repository>.pie-menu-editor). The module name follows the repository’s ID, so the comparison ignores the hyphen / underscore difference.

  • When several packages are listed, the intended installation is identified before any edit. The snippet raises RuntimeError with the list.

  • The pme variable from the explicit import is the same API as the alias. Code that uses it omits import pme.

Quick start¶

import pme

# Runtime package identity (Legacy add-on or Blender Extension)
addon_id = pme.ADDON_ID

# Find a menu
pm = pme.find_pm("My Pie Menu")
pm = pme.find_pm(uid="pm_7f3c2k3h")

# Invoke a menu
pme.invoke_pm("My Pie Menu")
pme.invoke_pm(uid="pm_7f3c2k3h")

# List menus
all_menus = pme.list_pms()
pie_menus = pme.list_pms(mode="PMENU", enabled_only=True)
tags = pme.list_tags()

# Execute code
result = pme.execute("bpy.ops.mesh.primitive_cube_add()")
print(result.success, result.error_message)

# Evaluate an expression
value = pme.evaluate("len(C.selected_objects)")

# Validate JSON
result = pme.validate_json(json_string)
for err in result.errors:
    print(err.code, err.message)

Backward compatibility¶

PME1’s pme.context and the props() command global remain available. Existing props() scripts inside PME command slots keep working.

# These still work in PME2
pme.context.open_menu("My Menu")
pme.context.event.mouse_x
pme.context.add_global("my_var", value)
props("MyCounter", 10)

New code uses pme.execute() and pme.invoke_pm().
